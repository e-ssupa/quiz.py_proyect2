
## Features

* Multi-wave progression system with an integrated transition indicator
* Strict input validation loop that handles invalid entries without skipping questions
* Custom status generator that calculates scores and overall intelligence tiers
* Playback looping system that allows users to easily restart the game

## Requirements

* Python 3.x

## How to Run

1. Clone this repository or download the source code.
2. Open your terminal or command prompt.
3. Navigate to the project directory:
   ```bash
   cd "C:\Users\Windows 10 Pro\Desktop\Python proyects\quiz"
   ```
4. Run the script:
   ```bash
   python quiz.py
   ```
